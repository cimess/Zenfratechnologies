# Zenfratech School Website

Welcome to the Zenfratech School Website project! This modern web application showcases the official online presence of Zenfratech, a technology-forward school dedicated to nurturing young minds. Built with React, Vite, React Router, and GSAP animations, this site offers a dynamic, user-friendly experience with well-structured pages covering essential information about the school.

---

## Features

- **Homepage**: Introductory content with classroom and campus images.
- **About**: Animated staff cards featuring key members of the Zenfratech team.
- **Admissions**: Enrollment process, steps, and downloadable forms.
- **Academics**: Detailed academic programs, curriculum overview, and class schedule.
- **Gallery**: Responsive image grid with hover zoom animations showcasing school life.
- **News & Events**: Latest news and upcoming activities with fade-in animations on scroll.
- **Contact**: Contact form with accessible validation and static contact information.
- **Staff**: Full staff directory with animated profile cards.
- **Student Resources**: Downloadable materials and links for student support.
- **Parent Resources**: Guides, newsletters, and event calendars for parents.

---

- **Node.js** (version 16 or higher recommended)
